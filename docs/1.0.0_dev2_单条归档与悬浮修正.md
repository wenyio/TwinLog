# 1.0.0_dev2 单条归档与悬浮修正

日期：2026-11-19。接续 dev1，正式版本保持 1.0.0，基准 commit 为 e4ba117；工作区修改尚未提交。

## 变更

- 单条抓取记录增加悬浮归档按钮和右键归档入口，支持恢复和撤销。状态存入 record.json，标题及备注修改保留归档状态，文件保持原位。
- 归档单条记录不影响其他记录或完整日志，在“已归档”按原连接分组显示；全选只选择当前范围内记录。归档当前查看记录后，日志和备注保持显示。
- 正在抓取的记录不可归档；已经结束的记录可以在连接期间归档。连接归档保留原行为，整组恢复后，原先单独归档的记录仍保持归档。整组归档下的记录恢复按钮提示先取消连接归档。
- 图标显示条件由 focus-within 改为悬浮或 focus-visible，鼠标点击留下的焦点不再让图标持续显示，键盘焦点仍能显示。图标预留空间，悬浮不移动文字。
