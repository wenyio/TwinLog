# 小窗与置顶

- 正式版本保持 1.2.0；独立测试构建：TwinLog_1.2.0_dev2.exe。
- 同一窗口切换，复用现有操作栏、标题备注、结果标记和采集操作；不新建采集器或第二个窗口。
- 自绘标题栏，置顶/切换仅用图标；最小化、最大化、关闭调用 Wails 原有接口，保留退出保存确认。
- 默认 350×620，最小 300×560；备注默认显示并填充剩余高度，抓取状态变化不调整窗口尺寸。右下角手柄调整整个窗口，保存小窗尺寸；恢复完整模式时恢复原窗口边界及置顶状态。
- 模式切换集中在 Go 桥接依次执行窗口操作，避免 Wails JS 窗口指令分派到不同 goroutine 后先缩窗、后改最小尺寸的竞态。

## 自动验证

本次代码通过 Go test、Go vet、前端生产构建，以及 test:startup、test:capture、test:scroll、test:window。界面测试使用模拟 Wails 桥接，无真实设备连接。

test:window 覆盖草稿与记录跨模式保留、标题备注修改、停止及 FAIL 标记、窗口高度不变而备注伸缩、300×560 无溢出、窗口尺寸和置顶恢复、键盘及鼠标缩放、保存失败阻止切换、关闭前保存。

## 桌面检查与边界

已启动编译后的 dev2，在未连接设备状态成功从主窗口切换到真实窄窗，看到置顶选中状态、图标标题栏及设备配置。初版 dev1 暴露了窗口指令竞态，已在 dev2 改为 Go 顺序桥接；dev1 不作为交付版本。

桌面后续检查检测到用户输入后停止，未继续操作。真实设备采集中切换、设备断线、不同 DPI、多显示器及真实最大化恢复仍需实机验证；目前恢复和保存一致性由模拟桥接的自动测试覆盖。
