# 1.1.1 默认上下分屏

日期：2026-11-19。上一轮已生成正式版 1.1.0，但版本字段及日志区修改尚未提交；其构建记录见 1.1.0_版本更新.md。本次在该正式构建基础上仅调整默认布局与按钮顺序，按修订号升为 1.1.1，不重复计算 1.0.0 至 1.1.0 的新增功能。

- 首次使用、布局模式无效或配置无法解析时默认上下分屏。有效布局偏好继续恢复，不强制覆盖用户此前选择。
