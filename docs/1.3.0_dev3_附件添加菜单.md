# 1.3.0_dev3 附件添加菜单

正式版本保持 1.3.0，基准提交 1e338b7；附件相关改动仍未提交。产物：build/bin/TwinLog_1.3.0_dev3.exe。

“＋”改用与行右键菜单相同的圆角、阴影和图标样式，通过独立浮层显示“选择文件…”与“从剪贴板粘贴 Ctrl+V”。菜单靠按钮右对齐，下方不足时向上弹出，不占用备注或附件列表布局。支持再次点击收起、外部点击关闭、方向键、Home/End、Esc 关闭并恢复焦点，滚动、切换记录和面板失效时关闭。

备注输入框空白提示改为“输入备注，可粘贴图片或文件作为附件”，同时增加独立的“备注”无障碍名称，普通文本粘贴行为保持。

本次前端生产构建、test:attachments、test:window、test:capture 通过。附件测试验证菜单不改变面板尺寸、按钮开关、外部关闭、Esc 焦点恢复、方向键、两种导入入口，以及 282×560 菜单边界。已检查模拟小窗菜单截图；实际 WebView2 和真实剪贴板来源未在本次实测。
