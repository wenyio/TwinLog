## 本次功能

- 停止抓取后，在右侧“标记结果”选择 PASS、FAIL 或待判定，自动保存。新建草稿及正在抓取的记录不提供标记入口。
- 左侧记录前显示 8px 灰色空心圈、绿色对勾或红色叉号；悬停信息包含完整结果。PASS / FAIL 按钮最小高度 44px，选中后强化边框并显示“已选”。
- 保留原备注结构与样式，不增加导出文件名预览。标记前保存待写入标题、备注；标记保存失败时保留最后成功保存的结果并提示错误。
- 结果保存在 record.json 的可选 result 字段，旧记录默认待判定，重命名和归档保留标记。人工结论与中断、过滤缺口等采集状态独立。
- 单条 ZIP 默认文件名及包内记录目录追加 _PASS 或 _FAIL；待判定不追加。批量导出外层 ZIP 和完整日志保持既有命名，各记录目录带自己的结果；日志正文、本地目录及日志文件名不变。
