# 小窗宽度与右侧定位

- 正式版本仍为 1.2.0，独立构建 TwinLog_1.2.0_dev3.exe。
- 每次进入小窗时读取主窗口右侧操作面板的实际 CSS 宽度：通常 308px，主窗口宽度不超过 1200px 时为 282px。旧的小窗宽度记忆不覆盖此宽度，仍保留高度记忆及进入后的手动缩放。
- 进入小窗时定位到当前显示器工作区右侧，保留 12 个逻辑像素的边距。尽量保留原纵向位置，必要时向上收回以避开底部任务栏。
- Windows 使用同一坐标系的实际窗口矩形和显示器工作区计算位置，处理负坐标显示器和 DPI 边距；恢复主窗口位置时使用绝对坐标，避免 Wails Windows GetPosition 绝对坐标与 SetPosition 工作区相对坐标不对称导致偏移。

## 本次验证

- Go test、Go vet、前端生产构建及 test:window 通过。窗口测试覆盖 308px/282px 随主窗口面板变化，以及忽略旧的 700px 宽度记忆。
- Go 位置计算测试覆盖主屏、左侧负坐标显示器、左侧任务栏、150% 缩放后的物理坐标。
- 本次未做真实多显示器与不同 DPI 下的桌面定位实测，计算测试不能代替该实测。
