# 1.3.0_dev1 记录附件

本次保持正式版本 1.3.0，不升版。基准提交：1e338b7。测试构建：build/bin/TwinLog_1.3.0_dev1.exe。

实现抓取记录级附件：多文件选择、Windows 图片和本地文件粘贴、主名重命名、系统打开与定位、回收站移除、ZIP 随记录导出。附件复制到 attachments，原文件保留，无额外数据库或 JSON 清单。文件复制、图片转换及导出删除与采集锁分开，Stop 可继续使用；退出导入确认在备注保存确认之后处理。

UI 使用备注下方折叠条，自动显示数量、文件名、大小和进度；小窗复用，默认折叠，最多约 3 行后内部滚动。重命名弹窗保留扩展名，冲突保留输入。Ctrl+V 尊重输入焦点，普通文本仍进入备注；Windows 文件剪贴板没有 DOM paste 事件时提供键盘后备检测。

本次自动验证通过：go test ./...、go vet ./...、前端生产构建，以及 test:attachments、test:capture、test:scroll、test:window、test:startup。Go 新增用例覆盖原文件保留、同名编号、主名与仅大小写重命名、重名拒绝、ZIP 中的最新名称及内容、失败/取消清理、无效路径和文件夹拒绝、复制期间 Stop 与导出/删除互斥、任务取消与退出期间拒绝新导入。前端用模拟桥接验证焦点规则、无 DOM paste 的键盘后备、目标记录固定、重命名重试与取消、小窗 282×560 布局。已检查模拟小窗截图；原生剪贴板来源不在模拟验证范围内。此文件仅代表本次环境，不代表后续版本。

已使用 build.ps1 完成 Windows/amd64 构建，随后前端细节更新并通过生产构建后，以 wails build -s 同步到同名独立测试产物；未覆盖正在运行的其他版本。

实机待验证：Windows 截图工具、画图、浏览器复制图片、资源管理器多文件在实际 WebView2 下的行为，系统关联打开与定位、回收站确认、导入期间退出确认、设备采集与大文件复制并行表现。未改写当前系统剪贴板或连接真实设备。

边界：不支持文件夹、虚拟文件和链接下载。原生 PNG 保留透明度，仅有 Windows 位图的来源保存为不透明 PNG。剪贴板图片最多 4000 万像素，原生 PNG 数据最多 256 MB，本地文件不限类型和内容大小。批次中某个文件失败时停止后续导入，已完成的附件保留。
