# 1.3.0_dev4 导出目录层级

正式版本保持 1.3.0，基准提交 1e338b7。独立测试构建为 build/bin/TwinLog_1.3.0_dev4.exe，包含工作区现有附件功能，不覆盖其他测试构建。导出层级修改单独提交，附件功能改动留在工作区。

针对单条记录导出的 ZIP 多套连接与记录目录的问题，按导出范围省略最外层目录：单条记录为“记录名.zip/日志”，单连接为“连接名.zip/记录目录/日志”，跨连接为“TwinLog_导出时间.zip/连接名/记录目录/日志”。日志指原有 android.log、mcu.log，备注和 record.json 同层，附件仍在 attachments/。连接信息、事件和可选 full/ 位于连接层；单条导出时位于 ZIP 根目录。

默认文件名随范围调整。连接名使用最新连接标题，未命名时沿用原连接目录名；跨连接的同名目录忽略大小写加序号，避免混合。记录目录继续使用原抓取时间、最新标题、结果及必要的重名序号。导出只改变 ZIP 内路径，不移动、重命名或修改源文件。

连接右键新增“导出整个连接”，导出该连接的全部记录及可用完整日志；连接中、抓取中或无可导出内容时禁用。整连接即使只有一条记录也保留记录目录。批量选择单连接的多条记录使用连接级结构，跨连接使用连接集合结构。
