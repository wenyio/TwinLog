## 行为

左侧列表滚动时，连接标题与该连接的“完整日志”作为同一块吸附在列表顶部。记录从其下方滚过，下一组连接到达时接替上一组。无完整日志时仅吸附连接标题；折叠时隐藏完整日志与记录，展开后恢复。

使用 CSS sticky，以连接分组为边界，不添加滚动监听或复制行。固定后的完整日志按钮沿用现有点击、选中与右键操作。
