# 日志工作区

## 抓取流程

- 新建抓取：入口只在右侧历史详情。未连接时先进入设备连接页；连接成功后进入抓取页并聚焦标题。已连接时直接在右侧显示“待开始”并聚焦标题。
- 启动默认显示设备连接页；连接失败留在设备页，可重试，不会开始抓取。断开后重新连接仍保留未开始的标题和备注。
- 未开始的标题和备注在本次运行内保留；查看历史记录后点新建可恢复。此时不创建抓取目录，不写历史记录。
- 开始成功：创建并选中左侧记录，显示“抓取中”，消费当前草稿。可空标题开始，界面显示“未命名”。开始失败时保留草稿。
- 抓取中和停止后均可编辑标题和备注，自动保存。停止、切换记录、导出和退出前等待保存，失败时保留原输入以便重试。新建时进入下一份空白草稿。
- 已中断的记录单独标注。右侧收起时，可在中间点“返回实时”回到草稿。
- 改标题不更改磁盘目录。导出时，ZIP 内的抓取目录使用原抓取时间和最新标题；空标题只用时间，重名加序号。
- 新建、开始和停止均不自动清屏。

验证命令：前端目录运行 `npm run test:capture`，使用模拟 Wails 接口覆盖草稿往返、返回实时、聚焦、空标题开始、自动保存、失败重试、导出及退出前保存和预览保留；不连接实际设备。

- 左侧保留记录列表和批量导出，可收起。
- 中间支持左右分屏、上下分屏、仅 MCU、仅 Android。
- 分屏中间的分隔线可拖拽：左右调整宽度，上下调整高度；两侧至少保留 20%。双击恢复均分，聚焦后可用方向键微调。
- 左右、上下分屏分别记住拖拽比例，重启后恢复。
- 右侧放置新建抓取、标题、开始抓取、应用选择、备注和设备设置，可收起。
- 抓取中，停止按钮固定显示在日志工具栏，不受右侧标签页或操作栏是否收起影响。
- 布局和侧栏状态保存在本机；切换显示保留预览、暂停状态和备注。
- 每个实时日志窗独立跟随；上滚固定当前预览，滚到底部或点击“回到最新”恢复。手动暂停只通过“回到最新”解除。右侧操作栏独立滚动。
- 页面保留操作名称、状态、保存反馈和错误；说明优先放在悬停提示中。

本轮验证：TypeScript/Vite 构建、Windows Wails 构建；模拟日志检查四种布局、隐藏通道继续更新、侧栏收起/恢复、布局记忆、1080×640 窗口、暂停/继续和清屏。实际 Windows 窗口检查已完成。本轮未连接设备进行采集验证。
拖拽调整验证：浏览器自动检查左右/上下拖拽、20%–80%边界、双击均分、方向键、重载比例恢复、单窗切换和1080×640窗口，均通过。
