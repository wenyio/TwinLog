# 首版验证记录

日期：2026-11-17；Windows amd64，Go 1.27.4、Wails 2.17.1、React 19、TypeScript。

已通过：

- npm run build：TypeScript 检查与 Vite 生产构建。
- npm install audit：0 vulnerabilities（本次安装结果）。
- go test ./... 与 go vet ./...。
- 7 个后台测试：串口所有切块边界/空行/CRLF；UID 过滤及重启 PID 变化/长行；full 与抓取分流、备注及 ZIP；UTF-8 预览跨块；中断恢复和文件替换；持续写入；空抓取与半个 CRLF 起点。
- 短时写入：15.7 MiB 输入同时写 full 和抓取文件，校验文件大小一致；本机约 90.8 MiB/s 输入速率，含抓取文件同步，不代表 USB 实机或全天性能。
- Wails Windows 生产构建，TwinLog.exe 约 11.8 MiB。
- 通过 computer-use 检查真实窗口布局、空状态与控件禁用状态，正常关闭窗口后进程退出。

未验证：真实 P19 双通道、热插拔、磁盘慢/满、隔离进程日志归属、8 小时稳定性。竞态检测未运行：当前环境未配置 cgo C 编译器；普通 go test 和 go vet 已通过。

实现取舍：

- 使用 UID 匹配，覆盖普通 App 重启及同 UID 多进程；共享 UID 拒绝单独抓取；隔离 UID 进程不在过滤范围中，系统相关日志仍在 full。需要设备提供 UID 格式。
- 采集线程直接写入受锁保护的缓冲文件，不创建无界接收队列；磁盘长期阻塞仍可能引起上游丢失，不能保证任意环境零丢失。
- full/抓取不做文件轮转；单文件可增长，预览有固定上限，历史全文通过外部文本工具查看。
- 串口预览 UTF-8，正文原字节保留并插入时间戳。
- Go/Wails 运行时与系统 API 有原生实现，应用代码未使用 C/C++/C# 或 .NET。
- Terra 子 agent 已按请求启动，但平台连续投递空任务正文，未参与有效代码实现。
