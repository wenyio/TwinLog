# 0.2.1 黑白灰界面

验证日期：2026-11-17。

## 变化

- 界面以浅灰背景、白色面板和深灰文字为主，主按钮、标签、历史选中态、复选框和分隔线统一使用灰阶。
- 提高辅助文字与占位提示的对比度；连接、采集、错误及待保存状态保留少量颜色。
- 常用颜色集中为 CSS 变量，不改变采集与日志保存逻辑。
- package.json、锁文件和 Wails 产品版本统一升级为 0.2.1；界面与 Windows 资源继续使用现有版本来源。

## 本次验证

- `npm.cmd run build` 通过；模拟数据截图检查了 1440 × 900 和 1080 × 640 两种尺寸，没有页面横向溢出。
- `npm.cmd run test:capture`、`npm.cmd run test:scroll` 通过，使用模拟 Wails 桥接与日志数据。
- `go vet ./...` 通过；正式构建脚本内的 `go test ./...` 通过。
- 隔离构建目录首次缺少 Go 嵌入所需的 frontend/dist；先构建前端后，重跑 `build.ps1` 成功，使用 Wails v2.17.1 和项目本地 Go。
- `build/bin/TwinLog.exe` 被无窗口的旧冒烟测试进程占用，其 PID 与 `.tools/history-smoke-pid.txt` 一致；未强制终止，改在 `.tools/release-0.2.1` 使用当前源码运行正式构建脚本。
- 交付为 `build/bin/TwinLog-0.2.1.exe`，Windows FileVersion 与 ProductVersion 均为 0.2.1；源码文件与隔离构建目录逐一核对一致。
- 已启动新版 Windows 原生窗口，确认界面显示 v0.2.1，灰阶配色和设备连接面板显示正常。启动后保持未连接状态。
