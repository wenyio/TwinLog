# 1.0.0_dev1 记录交互优化

日期：2026-11-19。基于 `e4ba117` 开发；正式版本保持 `1.0.0`，本次测试产物为 `build/bin/TwinLog_1.0.0_dev1.exe`。

## 变更

- 抓取面板顶部固定提供“新建抓取”，未连接时也可准备草稿。历史标题以文本显示，经右键“重命名记录”或右侧入口显式修改；抓取中标题和备注、历史备注仍自动保存。新草稿不写入旧记录。
- 左侧默认隐藏复选框和批量操作区；“批量管理”进入、“完成”退出。全选仅包含当前范围的记录，切换当前/已归档或退出批量模式时清空选择。包名展示保留。
- 行尾省略号替换为右键菜单，支持 Shift+F10、菜单键、方向键、Home/End、Esc 和焦点返回。右键不切换日志或勾选记录。
- 悬浮或键盘聚焦连接行时显示归档/取消归档图标，右键也可操作。整次连接归档，保存在 session.json；文件保持原位，支持撤销，当前查看内容保持不变。归档前先保存待写入字段，失败时不切换状态；正在连接的会话不可归档。无有效 session.json 的旧分组不提供归档入口。
- 抓取期间导出限制保持原状，未增加导出并行处理。
- build.ps1 增加 OutputName 参数，并按完整路径检查目标 exe 是否正在运行；默认仍输出 TwinLog.exe。
