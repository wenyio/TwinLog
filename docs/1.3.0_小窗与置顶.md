# 1.3.0 小窗与置顶

以 1.2.0 发布提交 `03707d2` 为基准，本次新增兼容的小窗与置顶功能，正式版本升至 1.3.0。界面版本取自 frontend/package.json，与 npm 锁文件及 Windows 产品版本保持一致。

## 变更

- 同一窗口切换完整模式与小窗，复用原有操作面板和状态。标题、备注、抓取结果、连接与采集操作保持一致，切换前保存待写入内容，保存失败时保留当前模式并提示。
- 标题栏在最小化按钮左侧提供置顶和小窗图标；小窗默认置顶，展开后恢复原窗口尺寸、位置、最大化及置顶状态。关闭沿用保存与退出确认流程。
- 每次进入小窗时，宽度匹配主窗口右侧面板，通常为 308px，窄主窗口为 282px。忽略旧的宽度记忆，保留高度记忆；默认高度 620px，最小尺寸 282×560。
- 小窗靠当前显示器工作区右侧放置，留约 12 个逻辑像素边距，并限制纵向位置以避开任务栏。Windows 位置计算和恢复使用绝对物理坐标。
- 备注默认显示并填充剩余高度。新建、开始与停止抓取不改变窗口尺寸，由备注区随其他内容伸缩。可拖动窗口边缘、备注右下角手柄，或用手柄方向键调整尺寸。
- 窗口切换通过单个 Go 桥接依次执行，避免窗口尺寸与最小尺寸指令竞态。隐藏日志区时忽略其无可见高度的滚动事件，避免误暂停实时预览。

## 验证

2026-11-20，本次 1.3.0 源码通过以下验证：

- `go test ./...`、`go vet ./...`。
- `./build.ps1` 正式构建成功，包含前端 TypeScript 检查与 Vite 生产构建，产物为 `build/bin/TwinLog.exe`（12,532,736 字节）。EXE 文件版本、产品版本和前端版本均为 1.3.0。
- `npm.cmd run test:window`：覆盖 308px/282px 面板匹配宽度、忽略旧宽度、固定窗口高度与备注伸缩、共享记录及结果、窗口与置顶恢复、鼠标与键盘缩放、保存失败阻止切换及关闭前保存。
- `npm.cmd run test:capture`、`npm.cmd run test:scroll`、`npm.cmd run test:startup` 均通过，覆盖采集交互、日志滚动和生产资源启动回归。界面测试使用模拟 Wails 桥接，不连接真实设备。
- Windows 位置计算测试覆盖主屏、负坐标显示器、左侧任务栏和 150% 缩放后的物理坐标。

历史测试构建记录见 1.2.0_dev2、1.2.0_dev3 对应文档。

实机边界：此前 dev2 在未连接设备状态完成真实主窗口到小窗切换检查；1.3.0 正式程序尚未进行桌面操作验证。真实设备采集中切换、断线、不同 DPI、多显示器定位与真实最大化恢复仍需实机验证，模拟桥接和几何计算测试不能替代这些检查。
