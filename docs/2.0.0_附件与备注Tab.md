# 2.0.0 附件与备注 Tab

以 1.3.0 发布提交 1e338b7 为基准，本次发布包括其后 b69350f 的导出范围调整及本次附件功能。附件是兼容新增功能，但 ZIP 导出相对路径改变属于不兼容变更；按项目约定以最高影响统一升主版本至 2.0.0。原始采集目录与旧记录读取保持兼容。界面取 frontend/package.json 版本，npm 锁文件及 Windows 产品版本同步。

## 变更

- 记录支持选择普通文件和粘贴图片、文件作为附件，保存到记录的 attachments/ 子目录。复制导入，不修改来源；同名自动编号。大文件显示进度并可取消，停止抓取不受导入影响，退出时处理未完成导入。附件默认随记录导出。
- 右侧下方使用“备注 / 附件 · 数量”Tab，共用剩余空间，文本和文件页内部滚动；去掉抓取面板外层滚动与备注上方横线。结果标记布局保持原样。切换保留备注和滚动位置，添加成功显示附件页，后台记录导入完成不抢当前页。
- 文件单击打开、双击重命名，保留扩展名；长文件名省略主名。右键菜单提供打开、定位、重命名和移除，悬浮或聚焦显示移除按钮。移除确认后回收记录副本。
- 添加菜单提供选择文件与剪贴板粘贴，备注提示可粘贴附件。成功信息短暂显示在 Tab 栏，错误在附件页展开和关闭，重命名错误留在对话框，设备与采集通知不受附件操作影响。
- 纳入 b69350f 的整连接导出及按范围简化 ZIP 层级：单记录内容位于 ZIP 根目录，单连接保留记录目录，跨连接保留连接与记录目录。此处会改变旧版 ZIP 的相对路径，使用脚本按固定 ZIP 路径提取文件时需对应调整。原始采集目录不移动或改写。
