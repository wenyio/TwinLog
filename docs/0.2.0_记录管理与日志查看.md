# 0.2.0 记录管理与日志查看

验证日期：2026-11-17。

## 变化

- 左侧新增全选、半选状态、选中数量和删除所选；当前抓取不能勾选，抓取期间禁止删除。
- 删除使用默认 No 的 Windows Yes / No 确认框；先保存备注，再确认，记录移至保存目录的 `.twinlog-trash/删除时间/`。保留日志、备注和 `restore.json` 原路径映射，会话 `full` 不移动。
- 删除前验证整批记录范围；拒绝保存目录之外、完整日志和会话目录。移动失败尝试回滚，列出部分失败的回收位置；列表刷新排除回收目录并清理失效选择。
- 点击记录显示对应 MCU / Android 日志；历史标题和提示区分实时预览，可返回实时。停止抓取后显示该条已保存日志，后台完整日志继续采集。
- 每路只读取文件末尾最多 256 KiB、最多显示 2000 行，保留超长单行尾部并处理 UTF-8 边界。显示文件总大小；全文通过打开记录目录查看。
- 界面版本来自 package.json；锁文件、Wails 产品版本统一为 0.2.0，构建时检查版本一致和旧进程占用。
