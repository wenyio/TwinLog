# 1.1.1_dev1 采集中右键菜单修复

日期：2026-11-20。本次修复基于 commit `3c1a757`，正式版本保持 `1.1.1`。

## 原因与修复

- 后台连接后每 120 毫秒推送状态，父组件重新渲染时重新创建可见连接数组，触发列表的菜单关闭 effect。现在使用 `useMemo`，仅在连接列表数据或归档筛选变化时重新计算数组。
- 菜单的全局捕获滚动监听会收到右侧日志自动滚动事件。现在只在滚动目标包含菜单所属列表行时关闭菜单。
- 保留列表数据、连接或抓取状态变化时的关闭行为，并补充连接目录和当前抓取记录路径变化时关闭，避免保留过期的操作权限。
