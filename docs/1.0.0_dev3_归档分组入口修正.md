# 1.0.0_dev3 归档分组入口修正

日期：2026-11-19。正式版本保持 1.0.0，基准 commit e4ba117，工作区修改尚未提交。

修正 dev2 中单条归档后，“已归档”里的所属连接分组仍显示“归档连接”的问题。该分组用于归类记录，连接本身并未归档；现在隐藏其连接归档图标及右键归档入口，记录行保留“取消记录归档”。整次连接已归档时，连接行仍提供取消归档入口。

前端构建和 test:capture 通过，新增断言覆盖单条归档分组的图标及菜单隐藏、记录恢复入口保留；原有整组归档恢复回归通过。

独立测试构建：build/bin/TwinLog_1.0.0_dev3.exe。未停止、覆盖或启动运行中的正式版和 dev2，未操作真机或用户日志；Windows 桌面验收留给用户。
